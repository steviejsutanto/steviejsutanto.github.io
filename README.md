# Stevie J. Sutanto

Static portfolio website published through GitHub Pages at
[steviejsutanto.github.io](https://steviejsutanto.github.io/).

## Preview

From this directory, serve the site over HTTP:

```bash
npx --yes serve .
```

Open the local URL shown by `serve`. The site is plain HTML, CSS, and JavaScript;
GitHub Pages publishes the repository root from `main` without a build step.

## Portfolio Updates

Public media is optimized for the website and source-quality originals are kept
outside this repository. See [portfolio/README.md](portfolio/README.md) for
adding works, editing metadata, and regenerating portfolio data.
